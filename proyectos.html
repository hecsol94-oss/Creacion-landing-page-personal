Proyecto Integrador de gestion de citas Edna Moda

El Proyecto Integrador representa la culminación del aprendizaje en los módulos de Programación, Bases de Datos y Entornos de Desarrollo.

  • Introducción y Objetivos: Contextualización del proyecto basado en el taller de sastrería de "Edna Moda". Se establecen las metas principales: gestionar un sistema CRUD de citas, clientes y empleados con reglas de negocio complejas, como la restricción de encuentros entre héroes y villanos.
  • Tecnologías y Metodología: Uso de Java (JDK 21) bajo el patrón MVC (Modelo-Vista-Controlador) y Swing para la interfaz. Se aplicó la metodología ágil SCRUM, organizada en Sprints y gestionada a través de Trello y GitHub para el control de versiones.
  • Desarrollo de Software (Entornos y Programación): Creación de diagramas de Casos de Uso y de Clases (UML) para definir la lógica. Implementación de validaciones robustas, permisos diferenciados por roles (Aprendiz, Oficial, Maestro) y pruebas unitarias con JUnit para garantizar la estabilidad del código.
  • Diseño de Datos (Bases de Datos): Elaboración del Modelo Entidad-Relación y su transformación al Modelo Relacional. La base de datos en MySQL fue normalizada para evitar redundancias, asegurando la integridad referencial mediante claves primarias, foráneas y restricciones de integridad.
  • Resultados y Futuro: Conclusiones sobre la consolidación del trabajo en equipo y la entrega de un producto funcional. Se proponen mejoras futuras como la migración a una arquitectura cliente-servidor y el uso de un ORM (Hibernate) para la persistencia de datos.

Despliegue de LMS Moodle en AWS

Este proyecto final de la asignatura de Fundamentos de la computacion en la nube, consistió en el diseño de una infraestructura de nube escalable y segura bajo el modelo de responsabilidad compartida de AWS.

  • 1. Red en la nube (VPC): Se configuró una Amazon VPC en la región us-east-1 con 2 zonas de disponibilidad para asegurar la alta disponibilidad del sistema. Se segmentó la red en una subred pública (10.0.0.0/24) con Internet Gateway y una privada (10.0.1.0/24) para proteger los datos.
  • 2. Servidor Web (EC2): Se lanzó una instancia t3.micro (Amazon Linux 2023). El acceso se restringió mediante un Security Group que permite SSH (puerto 22) para gestión y HTTP (puerto 80) para los usuarios finales.
  • 3. Base de Datos (RDS): Se implementó MySQL en Amazon RDS bajo una subred privada. Se configuró para aceptar tráfico exclusivamente desde el servidor EC2 (puerto 3306), desactivando el acceso público para garantizar la integridad de la información.
  • 4. Instalación de Moodle: Se preparó el entorno con Apache y PHP, instalando el núcleo de Moodle y configurando el directorio moodledata fuera del acceso público por seguridad. Se vinculó satisfactoriamente la aplicación con el endpoint de RDS.
  • 5. Gestión y Pruebas: Se asignó una Elastic IP para mantener un direccionamiento estático y evitar fallos en los enlaces internos al reiniciar la instancia. Se validó el sistema creando usuarios (Admin, Profesor, Alumno) y completando un ciclo académico real con entrega y calificación de tareas.
  • 6. Alta Disponibilidad y Almacenamiento (EFS): Se evolucionó a una arquitectura multi-instancia mediante la creación de una AMI (Amazon Machine Image) personalizada. Para la persistencia de archivos compartidos (moodledata), se implementó Amazon EFS, configurando reglas NFS (puerto 2049) para permitir la conexión de múltiples nodos simultáneos.
  • 7. Balanceo de Carga (ALB): Se desplegó un Application Load Balancer (ALB) vinculado a un Target Group con dos instancias activas. Se configuró el punto de acceso único mediante el DNS del balanceador, permitiendo la distribución inteligente del tráfico y garantizando la resiliencia del servicio ante fallos de instancia.

Creación de Web Corporativa Responsive

Este proyecto se centra en el diseño y desarrollo de una plataforma web completa bajo estándares de Lenguaje de Marcas, priorizando la estructura semántica, la limpieza del código y la experiencia de usuario.

  • Estructura Semántica HTML5: Implementación de una arquitectura sólida dividida en secciones operativas: Home, Áreas de actuación para servicios, una sección de "Quiénes somos" y un sistema de contacto avanzado.
  • Formularios Técnicos: Desarrollo de un formulario de contacto integral utilizando todos los elementos de validación y tipos de datos nativos de HTML5 para garantizar una interacción eficiente y segura.
  • Componentes de Navegación: Creación de un menú desplegable dinámico basado exclusivamente en listas HTML y CSS, logrando un aspecto visual atractivo mediante solapas desplegables sin dependencia de scripts externos.
  • Diseño Adaptativo (Responsive): Optimización total de la interfaz mediante Media Queries para asegurar una visualización perfecta en cinco escenarios: resoluciones superiores a 1300px, tablets y teléfonos (tanto en posición vertical como horizontal).
  • Despliegue y Gestión: Investigación y ejecución del alojamiento del sitio en plataformas como GitHub Pages, aplicando metodologías de organización, control de versiones y limpieza de código exigidas en entornos laborales.
