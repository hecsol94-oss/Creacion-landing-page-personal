PROYECTOS Y EXPERIENCIA

Gestion de citas Edna Moda

desarrollo de una aplicación de gestión para el taller de Edna Moda en Java e integracion de MySQL. 2026

Este proyecto representa la culminación del aprendizaje en los módulos de Programación, Bases de Datos y Entornos de Desarrollo. Consiste en una aplicación robusta desarrollada bajo el patrón MVC (Modelo-Vista-Controlador) utilizando Java Swing para la interfaz gráfica. Se diseñó e implementó una base de datos relacional en MySQL, normalizada para evitar redundancias y asegurar la integridad de los datos mediante claves primarias y foráneas. La lógica de negocio permite gestionar un sistema CRUD completo para citas, clientes y empleados, aplicando reglas complejas de negocio y validaciones de datos con JUnit. El desarrollo se gestionó bajo metodología ágil SCRUM, utilizando Trello para la organización y GitHub para el control de versiones, demostrando capacidad para construir software funcional y escalable.

Despliegue de LMS Moodle

diseño de una infraestructura de nube escalable y segura bajo el modelo de responsabilidad compartida de AWS. 2026

Este proyecto consistió en el despliegue profesional de una plataforma e-learning utilizando los servicios centrales de Amazon Web Services (AWS). Se diseñó una red personalizada mediante Amazon VPC segmentada en subredes públicas y privadas para garantizar la seguridad de los datos. La arquitectura incluye una instancia EC2 (Amazon Linux 2023) para el servidor web y Amazon RDS (MySQL) para la base de datos, configurada con acceso restringido mediante Security Groups. Para asegurar la persistencia y escalabilidad, se implementó Amazon EFS como almacenamiento compartido y se evolucionó el sistema hacia la alta disponibilidad mediante el uso de una AMI personalizada y un Application Load Balancer (ALB). Se validó el entorno realizando un ciclo académico completo, demostrando competencias en administración de sistemas Linux, redes y soluciones de infraestructura como servicio (IaaS).

Web Corporativa responsive

diseño y desarrollo de una plataforma web completa bajo estándares de HTML Y CSS, 2026

Este proyecto consistió en el desarrollo integral de una plataforma web multiplataforma, priorizando un diseño "Mobile-First" y una adaptabilidad total a diversos dispositivos. Se implementaron técnicas avanzadas de CSS3, como los floats o los display, para la creación de layouts dinámicos que garantizan una visualización óptima tanto en monitores de escritorio como en terminales móviles. La arquitectura del sitio se basó en estándares de HTML5 semántico, mejorando significativamente el posicionamiento SEO y la accesibilidad para lectores de pantalla. Se gestionó una hoja de estilos modular y organizada, permitiendo un mantenimiento eficiente del código y una carga de recursos optimizada. La interfaz incluye elementos interactivos y microinteracciones que enriquecen la experiencia del usuario final sin depender de bibliotecas externas. El resultado es un producto digital robusto, escalable y visualmente coherente que cumple con las exigencias del desarrollo web moderno. Este trabajo avala una base técnica sólida en el maquetado profesional y la resolución de problemas de diseño responsivo.
